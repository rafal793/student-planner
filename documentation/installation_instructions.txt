--------------------------------------------------------------------------------
1. REQUIREMENTS
--------------------------------------------------------------------------------

  Python .................. 3.9 or newer (recommended: 3.10–3.12)
  System .................. Windows 10/11, Linux, or macOS
  Internet ................ needed for the first library install (pip)
  Free disk space ......... about 500 MB (venv + dependencies)

The app uses Kivy for the graphical interface and SQLite (built into Python)
for local data storage.


--------------------------------------------------------------------------------
2. INSTALL PYTHON
--------------------------------------------------------------------------------

WINDOWS
-------

  1. Go to: https://www.python.org/downloads/
  2. Download Python 3.9+ (for example Python 3.12).
  3. Run the installer.
  4. IMPORTANT: on the first screen, check “Add python.exe to PATH”.
  5. Click “Install Now” and finish the setup.
  6. Check the install in Command Prompt or PowerShell:

       python --version
       pip --version

     You should see a Python version (for example Python 3.12.x) and pip.

LINUX
-----

  Most distributions include Python in their package manager:

  Debian / Ubuntu:
    sudo apt update
    sudo apt install python3 python3-pip python3-venv

  Fedora:
    sudo dnf install python3 python3-pip

  Check:
    python3 --version
    python3 -m pip --version

  Kivy system libraries on Linux:

  Debian / Ubuntu:
    sudo apt install -y python3-dev ffmpeg libsdl2-dev libsdl2-image-dev \
      libsdl2-mixer-dev libsdl2-ttf-dev libportmidi-dev libswscale-dev \
      libavformat-dev libavcodec-dev zlib1g-dev

macOS
-----

  1. Install Python from https://www.python.org/downloads/
     OR with Homebrew:

       brew install python3

  2. Check:
       python3 --version
       python3 -m pip --version


--------------------------------------------------------------------------------
3. GET THE PROJECT
--------------------------------------------------------------------------------

  Clone the repository or unpack the project archive, then go into the
  project folder:

    git clone <repository-url>
    cd student-planner

  If you do not use Git, just unpack the project folder and open it in
  a terminal.


--------------------------------------------------------------------------------
4. SET UP A VIRTUAL ENVIRONMENT (RECOMMENDED)
--------------------------------------------------------------------------------

  Use a Python virtual environment (venv). It keeps project libraries
  separate from the rest of your system.

  Windows:
    python -m venv venv
    venv\Scripts\activate

  Linux / macOS:
    python3 -m venv venv
    source venv/bin/activate

  After activation, the terminal prompt shows (venv).

  To leave the environment, run: deactivate


--------------------------------------------------------------------------------
5. INSTALL REQUIRED LIBRARIES
--------------------------------------------------------------------------------

  All project dependencies are listed in requirements.txt.

  OPTION 1 — install script (recommended)

  Windows — run this in the project folder:
    scripts\install_requirements.bat

  Linux / macOS:
    chmod +x scripts/install_requirements.sh
    ./scripts/install_requirements.sh

  OPTION 2 — manual install with pip

    python -m pip install --upgrade pip
    python -m pip install -r requirements.txt

  On Linux / macOS, use “python3” instead of “python” if that is what
  your system uses.

  What is in requirements.txt:

    kivy   — graphical user interface (needed to run the app)
    Pillow — image support used by the UI
    pytest — unit tests (PYTHONPATH=code python -m pytest code/tests/)

  NOTE: To build a Windows .exe you also need pyinstaller
  (pip install pyinstaller). You do not need it to run the app from source.


--------------------------------------------------------------------------------
6. OPTIONAL IDE SETUP
--------------------------------------------------------------------------------

  VISUAL STUDIO CODE

  If you use VS Code, install these extensions:

    Python  — ms-python.python
              Python support, run scripts, venv

    Pylance — ms-python.vscode-pylance
              code hints and analysis (often installed with Python)

  After you open the project folder, VS Code should detect the venv
  interpreter — select it from the bottom status bar
  (Python 3.x.x ('venv')).

  PYCHARM / OTHER IDES

  Point the IDE to the Python interpreter inside your venv, then run
  app.py.


--------------------------------------------------------------------------------
7. RUN THE APPLICATION
--------------------------------------------------------------------------------

  Make sure you are in the project folder and (if you use it) the venv
  is active.

    python app.py

  On Linux / macOS:

    python3 app.py

  After start, the Student Planner window should open.

  RUN FROM A .EXE FILE (WINDOWS ONLY)

  A ready build is not part of the repository by default. After you build
  it (see below), you will find the program here:

    dist\StudentPlanner\StudentPlanner.exe

  Important:
    - the .exe works only on Windows;
    - run it from the full dist\StudentPlanner\ folder (including the
      _internal subfolder);
    - on Linux and macOS, run the app from source (python app.py).

  To build the .exe yourself (Windows):

    pip install pyinstaller
    scripts\build.bat

  The output will be in dist\StudentPlanner\.


--------------------------------------------------------------------------------
8. DATABASE
--------------------------------------------------------------------------------

  The app uses a local SQLite file:

    data/student_planner.db

  On first run (when the database is missing or has no subjects), the app
  creates the tables and inserts sample demo data (seeder). If demo
  subjects are already there, their dates are refreshed relative to today
  so the calendar shows tiles right away.

  The repository may already include data/student_planner.db — the app
  uses that file directly. You do not need to copy it to AppData or any
  other system folder.

  HOW TO SWITCH TO YOUR OWN DATA

  1. In the app, delete the sample subjects (subject details screen).
  2. Add your own subjects with the “Add subject” form.
  3. Do not leave the database completely empty before a restart — if
     there are no subjects, the seeder will insert sample data again.

  Optional: full reset of the database to fresh demo data:

    PYTHONPATH=code python -m tests.create_default_values

  Windows (PowerShell):
    $env:PYTHONPATH="code"; python -m tests.create_default_values

  Before you replace or delete data/student_planner.db, make a backup
  (for example data/student_planner_backup.db).


--------------------------------------------------------------------------------
9. RUN TESTS (OPTIONAL)
--------------------------------------------------------------------------------

  In the project folder:

    PYTHONPATH=code python -m pytest code/tests/ -q

  Windows (PowerShell):
    $env:PYTHONPATH="code"; python -m pytest code/tests/ -q

  The tests check things like calendar logic, the database, forms, and
  notifications.


--------------------------------------------------------------------------------
10. TROUBLESHOOTING
--------------------------------------------------------------------------------

  Problem: “python” is not recognized
  Solution: On Windows, check “Add to PATH” when installing Python,
            or use: py -m pip / py app.py

  Problem: Import error for kivy
  Solution: Run pip install -r requirements.txt again in an active venv

  Problem: The app does not start on Linux
  Solution: Install the SDL2 system packages (section 2)

  Problem: Empty data after start
  Solution: Start the app again (auto-seed on an empty database)
            or run: PYTHONPATH=code python -m tests.create_default_values

  Problem: The .exe does not work on Linux/Mac
  Solution: Use python app.py — the .exe is Windows-only

  Problem: No window after app.py
  Solution: Check the terminal messages; make sure Kivy installed
            without errors
